# LocalPick Korea (로컬픽 코리아)

외국인에게 **한국인이 실제로 가는 곳**을 알려주는 모바일 웹사이트입니다.
지원 언어: 영어 · 일본어 · 한국어 (오른쪽 위 버튼으로 바꿔요)

## 파일 구성

| 파일 | 하는 일 | 자주 고치나요? |
| --- | --- | --- |
| `data.js` | 도시·장소·필수템 같은 **내용** | 자주 (여기만 고치면 돼요) |
| `index.html` | 화면 디자인과 동작 | 가끔 |
| `photos/` | 장소 사진 넣는 폴더 | 사진 추가할 때 |
| `vendor/` | 지도(Leaflet)·글자 읽기(Tesseract) 프로그램 | 안 고쳐요 |

## 장소 추가하는 법

1. `data.js`를 엽니다.
2. `places: [` 아래에서 장소 한 덩어리(`{` 부터 `},` 까지)를 복사합니다.
3. 바로 아래에 붙여넣고 내용을 바꿉니다. `id`는 다른 장소와 겹치지 않게 지어주세요.
4. 저장하면 끝이에요.

카테고리(`cat`)는 7가지예요: `eat` 현지인 맛집 · `cafe` 카페 · `musteat` 꼭 먹을 음식 · `go` 가볼 곳 · `kids` 아이랑 · `tradition` 전통 · `specialty` 특산품

> ⚠️ 지금 들어 있는 장소는 **샘플**이에요. 직접 확인한 뒤 고치거나 진짜 로컬 가게로 바꿔주세요.

## 사진 넣는 법

1. 사진을 `photos/` 폴더에 넣습니다 (예: `photos/seoul-nogari.jpg`). 가로로 긴 사진이 잘 어울려요.
2. `data.js`에서 그 장소에 한 줄을 추가합니다:
   ```js
   photo: { src: 'photos/seoul-nogari.jpg', credit: '내 이름' },
   ```
3. 사진이 없으면 한글 간판 모양 그림이 대신 나와요.

> ⚠️ 직접 찍었거나 사용 허락을 받은 사진만 넣으세요. 인터넷에서 가져온 사진은 저작권 문제가 생길 수 있어요.

## 지도 핀 위치 고치는 법

1. 네이버 지도에서 장소를 찾고, 그 위치를 길게 누르거나 우클릭해 **좌표**(예: 37.5660, 126.9910)를 복사합니다.
2. `data.js`에서 그 장소의 `lat`(앞 숫자), `lng`(뒤 숫자)를 바꿉니다.
3. 음식처럼 특정 장소가 없으면 `lat`, `lng`를 빼면 돼요. 그러면 지도에 핀이 안 나와요.

지금 들어 있는 좌표는 **대략적인 위치**예요. 공개 전에 한 번씩 확인해 주세요.

## 메뉴판 번역기 고치는 법

`data.js` 맨 아래 `menu` 부분에 음식이 종류별로 들어 있어요.
음식 한 줄을 복사해서 `ko`(메뉴판 한글), `rom`(읽는 법), `name`·`desc`(언어별 이름·설명)를 바꾸면 됩니다.
`requests`는 주문할 때 같이 보여줄 요청 문장이에요 (예: 덜 맵게 해 주세요).

## 메뉴판 사진 스캔은 어떻게 돌아가나요?

- 사진 속 한글을 **휴대폰 안에서** 읽어요 (`vendor/ocr`의 Tesseract.js). 사진을 서버로 보내지 않아서 **비용이 0원**이에요.
- 읽은 글자를 `data.js`의 메뉴 사전과 맞춰 보고, 찾은 음식을 그 나라 말로 보여줘요. 가격도 같은 줄에서 찾아 붙여요.
- 사전에 없는 글자는 "다른 글자"로 보여주고, 구글 번역 링크(무료)로 번역할 수 있어요.
- 처음 한 번은 읽기 프로그램 약 6MB를 내려받아요.
- **사전에 음식을 많이 넣을수록 스캔이 똑똑해져요.**
- 메뉴판 글자가 사전 이름과 다르면(예: 돼지갈비찜 → 돼지갈비) "메뉴판 표기 · 가장 비슷한 음식"으로 따로 표시해요.
- 검증: `tests/ocr-check.js` (사용법은 파일 맨 위 설명 참고)

## 새 언어 추가하는 법 (예: 중국어)

1. `index.html`의 `LANGS`에 한 줄 추가: `{ id: 'zh-TW', label: '繁體中文' }`
2. `index.html`의 `T` 안에 같은 이름으로 화면 문장 묶음을 추가
3. `data.js`의 글마다 `'zh-TW': '...'` 번역 추가 (없으면 영어로 나와요)

## 내 컴퓨터에서 미리 보기

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다.

## 주소(URL)

- `#seoul` → 서울 목록 · `#seoul.map` → 서울 지도
- `#busan.musteat` → 부산의 "꼭 먹을 음식"
- `#all.kids` → 모든 도시의 "아이랑 갈 곳"
- `#shopping.pharmacy` → 약국 필수템
- `#menu` → 메뉴판 번역기

## 사용한 것

- 글자 읽기(OCR): [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0 라이선스, `vendor/ocr/TESSERACT-LICENSE`)
- 지도: [Leaflet](https://leafletjs.com) (BSD-2 라이선스, `vendor/LEAFLET-LICENSE`) + [OpenStreetMap](https://www.openstreetmap.org/copyright) 지도 타일
