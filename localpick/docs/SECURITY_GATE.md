# 보안 검토 — 2026-10-02

대상: 정적 LocalPick Korea 검토판. 이 기록은 일반 공개 승인이나 실제 기기 검증을 대신하지 않는다.

| 항목 | 근거·상태 |
|---|---|
| 비밀값 | 작성 소스·데이터에 키/토큰 패턴 없음. Sites 소스 자격증명은 메모리/stdin으로만 전달 |
| 인증·권한 | 앱 자체 계정·서버 쓰기 API 없음. Sites는 신규 소유자 비공개로 생성. 실제 배포 후 접근 정책은 영수증으로 확인 |
| 입력·출력 | 검색·OCR 결과의 HTML 이스케이프 확인. 40MB 파일 한도·60초 초기 로딩 제한·취소 토큰 확인. 통합본 비사진/손상 사진/취소·재시도와 부분 일치 주문 차단 직접 검증 |
| 의존성 | Leaflet 1.9.4, Tesseract.js 7.0.0. 새 패키지 설치 없음. JS 원본 일치 및 누락 라이선스 보완 |
| 개인정보 | OCR 사진 원본은 로컬 처리. 폰트·지도 타일 요청은 별도 외부 통신. 구글 번역 링크로 글자가 전달되는 점 안내 |
| 과금·남용 | 유료 API·DB·업로드 서버 없음. 파일·시간·동시 실행 제한은 기기 자원 보호용. 서비스 이용료 전체가 무료라는 뜻은 아님 |
| 잔여 위험 | 실제 기기 OCR, 샘플 장소·의약품/알레르기 문구 검증은 일반 공개 전 담당자 확인 필요 |

공식 보안 자료 검토: [Tesseract 과거 공지](https://github.com/advisories/GHSA-83rx-c8cr-6j8q)는 1.0.19 미만에 해당한다. [Tesseract core](https://github.com/naptha/tesseract.js-core/security), [Leaflet](https://github.com/Leaflet/Leaflet/security) 공개 보안 페이지도 확인했다. 이는 모든 취약점 부재를 증명하는 전수 감사는 아니다.

담당: Codex(코드·배포), Claude(OCR 보강). 콘텐츠와 실제 기기 검수 시한: 일반 공개 전.
